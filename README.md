# swamp-browser-test-evidence

Standalone source repository for `@mgreten/browser-test-evidence`. The extension
manifest and model are under `extensions/`.

Version `2026.08.28.1` adds strict Playwright normalization, execution and
digest checks, deterministic imported-run verification, and immutable
factory-bound browser verdicts. See
[`extensions/README.md`](extensions/README.md) for contracts, authority
boundaries, migration guidance, and examples.
